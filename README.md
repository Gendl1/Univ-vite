# Universal

Вёрстка лендинга новостного медиа по макету UI Kit: шапка, популярные материалы, рекомендации, блоки новостей, колонки, футер.

**Демо:** [https://gendl1.github.io/Univ-vite/]
**Репозиторий:** [https://github.com/Gendl1/Univ-vite]

## Стек

- HTML5
- SCSS (Sass)
- Vanilla JavaScript
- Vite

## Возможности

- Семантичная вёрстка многосекционного медиа-лендинга
- Адаптивная сетка (Flexbox / Grid), стили на SCSS
- Бургер-меню с переключением классов на JS
- Сборка и деплой через Vite + GitHub Pages

## Запуск локально

```bash
npm install
npm run dev
